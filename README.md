# 개인 투자 포트폴리오 대시보드

가상의 투자 데이터를 보여주는 브라우저용 대시보드입니다. 서버나 데이터베이스, 별도 패키지 설치 없이 실행할 수 있습니다.

## 실행 방법

1. 이 프로젝트 폴더에서 터미널을 엽니다.
2. 다음 명령을 실행합니다.

   ```sh
   node server.js
   ```

3. 브라우저에서 `http://127.0.0.1:8000`을 엽니다.
4. 실행을 마치려면 터미널에서 `Ctrl+C`를 누릅니다.

## 파일 안내

- `index.html`: 화면의 구조와 문구
- `styles.css`: 색상, 간격, 표, 차트 모양
- `app.js`: 가상 투자 데이터와 화면에 표시할 계산
- `server.js`: 파일을 브라우저에 전달하는 간단한 로컬 서버

가상 투자 데이터는 `app.js`의 `investments` 목록에서 확인할 수 있습니다. 평균 수익률은 각 투자건 수익률을 같은 비중으로 계산한 단순 평균입니다.
